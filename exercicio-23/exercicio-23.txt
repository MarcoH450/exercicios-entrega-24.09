CODIGO PROPOSTO

#include <stdio.h>
int main() {
int a = 5;
printf("%d\n", a);
printf("%d\n", a++);
printf("%d\n", ++a);
return 0;
}

RESOLUÇAO:

a primeira saida sera o valor 5
a segunda saida sera o valor 5 e atualizado para o valor 6
a terceira saida sera o valor 7 pois adiciona mais 1 ao 6 antes de printar o valor
